# آرکا | ARKA — فروشگاه مبلمان و دکوراسیون

وب‌سایت فروشگاهی مبل، صندلی، میز و این با تجربه‌ی خرید سه‌بعدی.
طراحی راست‌چین (RTL) با پالت کرم گرم، سرمه‌ای و برنجی، ساخته‌شده با React + Vite + Tailwind CSS.

## ✨ امکانات

- استودیوی محصول سه‌بعدی واقعی مبتنی بر WebGL و Three.js: مدل‌های مشِ صندلی، صندلی اپن، میز، کنسول، مبل و ست ناهارخوری با چرخش ۳۶۰ درجه، زوم و تغییر آنی رنگ رویه و پایه
- نمایشگر سه‌بعدی در صفحهٔ تجربه و مودال هر محصول؛ کنترل با درگ، اسلایدر، چرخ ماوس و کیبورد
- اتاق الهام تعاملی با نقاط خرید (shoppable hotspots) و پیش‌نمایش محصول در فضای نشیمن / ناهارخوری / آشپزخانه
- فروشگاه کاملِ فرانت‌اند: فیلتر و مرتب‌سازی، علاقه‌مندی‌ها، جستجوی زنده، سبد خرید، ثبت سفارش نمایشی و اعلان‌ها
- مودال مشاهده سریع محصول، نمایش ست کامل با تخفیف، نظرات مشتریان و خبرنامه
- طراحی کاملاً واکنش‌گرا (موبایل، تبلت، دسکتاپ) و سازگار با `prefers-reduced-motion`

## 🧱 تکنولوژی

| ابزار | نقش |
| --- | --- |
| React 19 + TypeScript | رابط کاربری |
| Vite 7 | باندل و توسعه |
| Tailwind CSS 4 | استایل و دیزاین‌توکن‌ها |
| Three.js | رندر WebGL و مدل‌های پارامتریک سه‌بعدی |
| lucide-react | آیکون‌ها |

## 🚀 اجرا

```bash
npm install
npm run dev      # محیط توسعه
npm run build    # خروجی تولید در dist/
npm run preview  # پیش‌نمایش خروجی
```

## 🧩 وضعیت فاز فعلی

این شاخه کاملاً فرانت‌اند است. تعاملات سبد خرید، سفارش، جستجو، شخصی‌سازی و نمایش سه‌بعدی در مرورگر اجرا می‌شوند؛ پرداخت، پنل مدیریت، پیامک، انبار، مارکت‌پلیس و ثبت واقعی سفارش هنوز به API یا بک‌اند متصل نیستند. مدل‌ها هم به‌صورت پارامتریک در Three.js ساخته می‌شوند تا در این فاز بدون وابستگی به فایل خارجی GLB/GLTF، رنگ رویه و پایه واقعاً روی مش سه‌بعدی تغییر کند.

## 📦 دارایی‌ها

تمام تصاویر و فونت‌ها **به‌صورت محلی** در پروژه قرار دارند و سایت هیچ درخواست خارجی برای تصویر یا فونت ندارد.

- `public/images/` — ۱۳ تصویر محصول و فضای داخلی
- `public/fonts/` — Vazirmatn (Arabic/Latin) و Cormorant Garamond (Normal/Italic) به فرمت WOFF2

## 📄 ساختار

```
src/
├── components/    # Header, Hero, Experience, Products, Visualizer, Story, Footer, Overlays
├── lib/           # داده محصولات (data.ts) و وضعیت فروشگاه (store.tsx)
├── utils/         # cn
├── fonts.css      # فونت‌های خودمیزبان
├── index.css      # دیزاین‌توکن‌ها و انیمیشن‌ها
└── App.tsx        # ترکیب صفحه، Reveal در اسکرول و مدیریت قفل اسکرول
```
